Safety

Cards can download and install files on your PC. GPU Selector checks them, but you decide what to trust.

What GPU Selector Always Does

A card can't turn any of these off.

  1. Checks files: a file must match the SHA256 the card gives. If it doesn't, it is refused.
  2. Asks first: a file with no SHA256 is only downloaded after you agree.
  3. Scans files: Windows Security scans downloads (files up to 50 MB).
  4. Warns about DLLs: a download with a DLL, EXE or script inside asks "Are you sure you want to install it?" before anything is installed.
  5. Asks before a card's DLL is used: once for each file. You can say no.
  6. Keeps originals: when a card's file takes the place of another program's file, the original is only renamed, never deleted.
  7. Never goes around Windows Security: if Windows Security flags a file, it is not installed.

What You Should Do

  1. Only load cards from people you trust.
  2. Read what a card will install before you press Install.
  3. If a warning surprises you, press Cancel.
A DLL is a program. It can do anything on your PC. Checks can't catch everything.

Card Packages (.zip)

  1. A package is the card's .json plus a folder next to it named <card name>_files.
  2. GPU Selector scans the .zip, then only keeps files the card names with a matching SHA256.
  3. When a package brings a DLL, GPU Selector tells you when you load it, and asks again before it is used.

No Warranty

  2. Use them at your own risk. Depth3D is not responsible for any problems a card causes.
  3. Cards made by other people are their own, and they are responsible for them.

For Card Makers

  1. Give every file a SHA256.
  2. Only use projects whose makers allow it, and name them on your card.
  3. If your card brings a DLL, share its source code too, like the DOOM card does.
