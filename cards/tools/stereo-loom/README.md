# Stereo Loom

A tool card for [Stereo Loom](https://github.com/Stereopticon-Org/StereoLoom) by effcol. It was called SR Loom before.

1. Downloads the newest `StereoLoom.exe` from its GitHub releases.
2. Adds a Launch button.
3. Three pages: About, Head Tracking and Keys.

This card used to be built into GPU Selector. It is in Cards on the House now, so it can change without an app update.
