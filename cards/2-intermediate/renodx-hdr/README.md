# RenoDX HDR

**Level 2: Intermediate.** HDR for games that never had it, or better HDR than their own. Needs an HDR display.

## Load it

1. Copy the card's link on the [website](https://blueskydefender.github.io/GPU-Selector-Cards/cards.html).
2. In GPU Selector: **Mods** tab, **+ Add Mod**, **Load from URL**, paste the link.
3. Or download `renodx_hdr.json` and use **Load from File**.

## What to look at

| Part | Field |
|---|---|
| Downloads from GitHub releases | `downloads` |
| ReShade add-ons, each for its own games | `addons` with `games` |
| The games it works with | `targetGames` |
| Turns on the game's HDR box | `hdr: true` on a target game |
